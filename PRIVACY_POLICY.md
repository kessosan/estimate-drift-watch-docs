# Privacy Policy — Estimate Drift Watch

Last updated: 14 September 2026

Estimate Drift Watch is a Jira Cloud application built on Atlassian Forge.

## Data accessed

The application accesses Jira data required to calculate estimate drift, including:

- issue key and summary;
- issue status;
- assignee information;
- Original Estimate;
- Remaining Estimate;
- Time Spent;
- relevant issue changelog entries used to reconstruct the first known estimate;
- Jira time-tracking configuration required to format durations.

## Purpose of processing

This information is used only to calculate and display estimate drift at issue and project level.

## Data storage

Estimate Drift Watch does not operate an external backend and does not store Jira issue data outside Atlassian infrastructure.

The application runs on Atlassian Forge.

## Data sharing

Estimate Drift Watch does not sell, rent, or share Jira customer data with third parties.

No Jira data is sent to external analytics, advertising, AI, or tracking services.

## External data transfers

The application does not intentionally transfer Jira customer data outside Atlassian-hosted infrastructure.

## Personal data

The application may access limited user information provided by Jira, such as the assignee name or account information, solely for displaying issue-related information.

This information is not used for profiling, advertising, or unrelated purposes.

## Data retention

Estimate Drift Watch does not maintain an independent external database of Jira customer data.

Data is retrieved from Jira when required to provide the application functionality.

## Security

The application uses Atlassian Forge authentication, authorization, and hosting mechanisms.

Access to Jira information is governed by the permissions granted to the application and the permissions of the Jira user.

## Changes to this policy

This Privacy Policy may be updated when the application functionality or data-processing practices change.

Material changes will be reflected by updating the date at the top of this document.
